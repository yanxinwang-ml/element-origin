# 臭氧（O₃）

## 基本信息

| 项目 | 内容 |
|---|---|
| 中文名 | 臭氧 |
| 英文名 | Ozone |
| 化学式 | O₃ |
| 相对分子质量 | 48.00 g/mol |
| 状态 | 常温下为淡蓝色气体，有特殊气味 |
| 组成元素 | **O**（8 号元素） |
| 化学键类型 | 极性共价键（O–O，存在共振结构） |
| 分子极性 | 极性分子 |

## 组成方式（原子如何结合）

V 形分子，键角约 116.8°；两个 O–O 键实际为单双键共振，键级约 1.5。

## 组成原理（为什么这样结合）

- 3 个氧原子中，中心氧与两侧氧各形成一个 O–O 键，并保留 1 对孤对电子；两个 O–O 键之间发生单双键共振，使两个键完全相同。
- 臭氧中氧的平均氧化态为 0，但分子不稳定，容易分解为普通氧气并放出能量。

## 组成元素的宇宙起源

该物质由以下元素组成，各元素的核合成起源见对应文档：

- [氧（O）](../elements/008-oxygen.md)：原子序数 8，太阳系中的主导来源为「大质量恒星核燃烧/超新星」。

## 常见制取

- 放电或紫外线：3O₂ ——放电/紫外→ 2O₃（闪电后的清新气味、复印机附近气味即源于此）。

## 主要用途

- 饮用水与空气消毒
- 臭氧层吸收太阳紫外线
- 氧化漂白
