# 氧化铝（Al₂O₃）

## 基本信息

| 项目 | 内容 |
|---|---|
| 中文名 | 氧化铝 |
| 英文名 | Aluminium Oxide |
| 化学式 | Al₂O₃ |
| 相对分子质量 | 101.96 g/mol |
| 状态 | 白色固体，熔点极高（约 2072°C），两性氧化物 |
| 组成元素 | **Al**（13 号元素）、**O**（8 号元素） |
| 化学键类型 | 离子键（Al³⁺–O²⁻），Al–O 有较强共价成分 |
| 分子极性 | 离子晶体 |

## 组成方式（原子如何结合）

离子化合物（晶体中 Al³⁺ 与 O²⁻ 规则排列）；α-Al₂O₃（刚玉）硬度极大。

## 组成原理（为什么这样结合）

- 铝失 3 个电子成 Al³⁺，氧得 2 个电子成 O²⁻，按电荷比 2:3 结合为 Al₂O₃；Al³⁺ 电荷高、半径小，Al–O 键结合很强，故熔点极高。
- 两性：既能与酸反应（Al₂O₃ + 6HCl → 2AlCl₃ + 3H₂O），也能与强碱反应（Al₂O₃ + 2NaOH + 3H₂O → 2Na[Al(OH)₄]）。

## 组成元素的宇宙起源

该物质由以下元素组成，各元素的核合成起源见对应文档：

- [铝（Al）](../elements/013-aluminum.md)：原子序数 13，太阳系中的主导来源为「大质量恒星核燃烧/超新星」。
- [氧（O）](../elements/008-oxygen.md)：原子序数 8，太阳系中的主导来源为「大质量恒星核燃烧/超新星」。

## 出现年代与宇宙纪元

- 元素铝来自恒星碳/氖燃烧（约 136 亿年前第一批恒星）；地壳中的铝几乎都以氧化铝相关矿物存在（铝土矿形成于数亿年的风化过程）；工业拜耳法 1888 年起。

## 产生方式

- 地质：富铝岩石（如长石）经数亿年风化富集成铝土矿。
- 燃烧/氧化：4Al + 3O₂ → 2Al₂O₃（铝在空气中迅速形成致密氧化膜，这是铝耐腐蚀的原理）。

## 常见制取

- 铝土矿拜耳（Bayer）法提纯：铝土矿用 NaOH 溶解、沉淀、煅烧得 Al₂O₃。
- 燃烧：4Al + 3O₂ ——点燃→ 2Al₂O₃（铝热反应也会生成）。

## 主要用途

- 电解炼铝原料
- 耐火材料与刚玉磨料
- 陶瓷与电子器件
