# 碳酸钙（CaCO₃）

## 基本信息

| 项目 | 内容 |
|---|---|
| 中文名 | 碳酸钙 |
| 英文名 | Calcium Carbonate |
| 化学式 | CaCO₃ |
| 相对分子质量 | 100.09 g/mol |
| 状态 | 白色固体（石灰石、大理石），难溶于水 |
| 组成元素 | **Ca**（20 号元素）、**C**（6 号元素）、**O**（8 号元素） |
| 化学键类型 | 离子键（Ca²⁺–CO₃²⁻），CO₃²⁻ 内部为共价键 |
| 分子极性 | 离子晶体 |

## 组成方式（原子如何结合）

离子化合物：Ca²⁺ 与 CO₃²⁻ 结合；CO₃²⁻ 为平面三角形共振离子。

## 组成原理（为什么这样结合）

- 钙以 Ca²⁺ 存在，碳酸根 CO₃²⁻ 由碳与三个氧共价结合（共振）形成；两者靠离子键构成晶体，难溶于水。
- 遇酸放出 CO₂：CaCO₃ + 2HCl → CaCl₂ + H₂O + CO₂↑（实验室制 CO₂ 的原理）；高温分解：CaCO₃ ——高温→ CaO + CO₂↑。

## 组成元素的宇宙起源

该物质由以下元素组成，各元素的核合成起源见对应文档：

- [钙（Ca）](../elements/020-calcium.md)：原子序数 20，太阳系中的主导来源为「大质量恒星核燃烧/超新星」。
- [碳（C）](../elements/006-carbon.md)：原子序数 6，太阳系中的主导来源为「低质量恒星死亡（AGB 星，s-过程）」。
- [氧（O）](../elements/008-oxygen.md)：原子序数 8，太阳系中的主导来源为「大质量恒星核燃烧/超新星」。

## 常见制取

- 天然矿藏（石灰石、大理石）开采；生物沉积（贝壳、珊瑚、蛋壳）。
- 化学合成：CaO + CO₂ → CaCO₃（如石灰乳吸收 CO₂ 碳化）。

## 主要用途

- 建筑材料与水泥
- 制取 CaO 与 CO₂
- 补钙剂与造纸填料
