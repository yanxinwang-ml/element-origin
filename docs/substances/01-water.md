# 水（H₂O）

## 基本信息

| 项目 | 内容 |
|---|---|
| 中文名 | 水 |
| 英文名 | Water |
| 化学式 | H₂O |
| 相对分子质量 | 18.02 g/mol |
| 状态 | 常温下为无色、无味液体 |
| 组成元素 | **H**（1 号元素）、**O**（8 号元素） |
| 化学键类型 | 极性共价键（O–H），分子间存在氢键 |
| 分子极性 | 极性分子 |

## 组成方式（原子如何结合）

V 形（弯曲形）分子，结构式 H–O–H，键角约 104.5°；O 原子带有 2 对孤对电子。

## 组成原理（为什么这样结合）

- 氧原子外层有 6 个电子，还需 2 个电子才能满足 8 电子（八隅体）稳定结构；两个氢原子各提供 1 个电子，与氧共用形成 2 个 O–H 共价键。
- 氧的电负性（3.44）明显大于氢（2.20），共用电子对偏向氧，使 O–H 键成为极性键；分子呈 V 形、电荷分布不对称，故水是极性分子。
- 一个水分子中带正电的氢与另一个水分子中带负电的氧之间形成氢键，使水的沸点、比热异常高，这也是冰能漂浮、水成为生命溶剂的原因。

## 组成元素的宇宙起源

该物质由以下元素组成，各元素的核合成起源见对应文档：

- [氢（H）](../elements/001-hydrogen.md)：原子序数 1，太阳系中的主导来源为「大爆炸核合成」。
- [氧（O）](../elements/008-oxygen.md)：原子序数 8，太阳系中的主导来源为「大质量恒星核燃烧/超新星」。

## 出现年代与宇宙纪元

- 元素层面：氢诞生于大爆炸（138 亿年前），氧诞生于约 136 亿年前的第一代大质量恒星；但早期宇宙温度太高，水分子无法稳定存在。
- 分子层面：第一批恒星死亡后（约 130 亿年前），星际分子云中开始出现水冰；太阳系中的水约在 46 亿年前的原行星盘中形成，地球海洋约于 44–38 亿年前定型。

## 产生方式

- 星际碰撞/表面反应：H、O、OH 在低温冰粒表面结合成 H₂O，气相反应 OH + H₂ → H₂O + H 也贡献一部分。
- 燃烧/化合：2H₂ + O₂ 点燃生成水（恒星内部氢燃烧的最终产物之一，也是火箭发动机的主要产水反应）。
- 地球来源：火山喷发的水蒸气冷凝，以及含水彗星/小行星在晚期重轰炸期（约 41–38 亿年前）撞击带来。

## 常见制取

- 化合：2H₂ + O₂ ——点燃→ 2H₂O（氢气在氧气中燃烧，也是火箭燃料的主要反应之一）。
- 电解：2H₂O ——通电→ 2H₂↑ + O₂↑（同时制得氢气和氧气）。
- 中和：H⁺ + OH⁻ → H₂O（酸与碱反应的实质）。

## 主要用途

- 生命活动必需溶剂
- 饮用、农业灌溉
- 工业冷却剂与反应介质
