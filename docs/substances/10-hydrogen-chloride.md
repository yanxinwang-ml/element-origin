# 氯化氢（盐酸）（HCl）

## 基本信息

| 项目 | 内容 |
|---|---|
| 中文名 | 氯化氢（盐酸） |
| 英文名 | Hydrogen Chloride |
| 化学式 | HCl |
| 相对分子质量 | 36.46 g/mol |
| 状态 | 纯品为无色气体；其水溶液即盐酸（无色液体，强酸） |
| 组成元素 | **H**（1 号元素）、**Cl**（17 号元素） |
| 化学键类型 | 强极性共价键（H–Cl） |
| 分子极性 | 极性分子 |

## 组成方式（原子如何结合）

双原子分子，结构式 H–Cl，单键相连。

## 组成原理（为什么这样结合）

- 氢（1 个电子）与氯（7 个价电子）各提供一个电子形成共用电子对：氢达到 2 电子稳定结构，氯达到八隅体。
- 氯电负性（3.16）远大于氢，共用电子对强烈偏向氯，H–Cl 键极性很强；溶于水后在水分子的作用下完全电离：HCl → H⁺ + Cl⁻，故盐酸是强酸。

## 组成元素的宇宙起源

该物质由以下元素组成，各元素的核合成起源见对应文档：

- [氢（H）](../elements/001-hydrogen.md)：原子序数 1，太阳系中的主导来源为「大爆炸核合成」。
- [氯（Cl）](../elements/017-chlorine.md)：原子序数 17，太阳系中的主导来源为「大质量恒星核燃烧/超新星」。

## 出现年代与宇宙纪元

- 元素氯来自恒星核合成；HCl 在恒星晚期抛出的冷气体和星际介质中存在（可通过星际分子谱线观测）。
- 地球：火山喷发释放大量 HCl；盐酸作为化学品自 15–16 世纪起被制备使用。

## 产生方式

- 恒星/星际：H + Cl 气相碰撞结合成 HCl；行星火山排气（地球火山喷发含大量 HCl）。
- 工业：H₂ + Cl₂ ——点燃→ 2HCl；NaCl + H₂SO₄（浓）——加热→ NaHSO₄ + HCl↑。

## 常见制取

- 化合：H₂ + Cl₂ ——点燃或光照→ 2HCl。
- 实验室：NaCl + H₂SO₄（浓）——加热→ NaHSO₄ + HCl↑。

## 主要用途

- 金属除锈与酸洗
- 制药与化工原料
- 实验室常用强酸
