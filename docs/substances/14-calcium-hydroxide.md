# 氢氧化钙（Ca(OH)₂）

## 基本信息

| 项目 | 内容 |
|---|---|
| 中文名 | 氢氧化钙 |
| 英文名 | Calcium Hydroxide |
| 化学式 | Ca(OH)₂ |
| 相对分子质量 | 74.09 g/mol |
| 状态 | 白色粉末，微溶于水（水溶液为澄清石灰水） |
| 组成元素 | **Ca**（20 号元素）、**H**（1 号元素）、**O**（8 号元素） |
| 化学键类型 | 离子键（Ca²⁺–OH⁻） |
| 分子极性 | 离子晶体 |

## 组成方式（原子如何结合）

离子化合物：Ca²⁺ 与两个 OH⁻ 通过离子键结合。

## 组成原理（为什么这样结合）

- 钙原子（2 个价电子）失去两个电子形成 Ca²⁺，与两个 OH⁻ 以离子键结合，满足电荷平衡。
- 其水溶液呈碱性（中强碱）：Ca(OH)₂ → Ca²⁺ + 2OH⁻（部分电离）；澄清石灰水遇 CO₂ 变浑浊：Ca(OH)₂ + CO₂ → CaCO₃↓ + H₂O，可检验二氧化碳。

## 组成元素的宇宙起源

该物质由以下元素组成，各元素的核合成起源见对应文档：

- [钙（Ca）](../elements/020-calcium.md)：原子序数 20，太阳系中的主导来源为「大质量恒星核燃烧/超新星」。
- [氢（H）](../elements/001-hydrogen.md)：原子序数 1，太阳系中的主导来源为「大爆炸核合成」。
- [氧（O）](../elements/008-oxygen.md)：原子序数 8，太阳系中的主导来源为「大质量恒星核燃烧/超新星」。

## 常见制取

- 生石灰消化：CaO + H₂O → Ca(OH)₂（剧烈放热，生成熟石灰）。

## 主要用途

- 建筑砂浆与涂料
- 中和酸性土壤
- 检验 CO₂ 的澄清石灰水
