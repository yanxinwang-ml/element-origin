# 常见无机物 · 组成方式与组成原理

本文档介绍常见无机物的**组成方式**（原子如何结合成分子/晶体）与**组成原理**
（为什么这样结合：八隅体规则、共价键/离子键、电负性与极性、共振、氢键等），
并关联组成元素的宇宙核合成起源。

| 物质 | 化学式 | 组成元素 | 主要键型 | 文档 |
|---|---|---|---|---|
| 水 | H₂O | **H**、**O** | 极性共价键（O–H），分子间存在氢键 | [查看](./01-water.md) |
| 氢气 | H₂ | **H** | 非极性共价键（H–H） | [查看](./02-hydrogen.md) |
| 氧气 | O₂ | **O** | 非极性共价键（O=O 双键） | [查看](./03-oxygen.md) |
| 氮气 | N₂ | **N** | 非极性共价键（N≡N 三键，键能约 946 kJ/mol） | [查看](./04-nitrogen.md) |
| 臭氧 | O₃ | **O** | 极性共价键（O–O，存在共振结构） | [查看](./05-ozone.md) |
| 过氧化氢 | H₂O₂ | **H**、**O** | 极性共价键（O–H、O–O） | [查看](./06-hydrogen-peroxide.md) |
| 二氧化碳 | CO₂ | **C**、**O** | 极性共价键（C=O），分子整体对称 | [查看](./07-carbon-dioxide.md) |
| 一氧化碳 | CO | **C**、**O** | 极性共价键（C≡O） | [查看](./08-carbon-monoxide.md) |
| 氨 | NH₃ | **N**、**H** | 极性共价键（N–H），分子间有氢键 | [查看](./09-ammonia.md) |
| 氯化氢（盐酸） | HCl | **H**、**Cl** | 强极性共价键（H–Cl） | [查看](./10-hydrogen-chloride.md) |
| 硫酸 | H₂SO₄ | **H**、**S**、**O** | 极性共价键（S=O、S–O、O–H） | [查看](./11-sulfuric-acid.md) |
| 硝酸 | HNO₃ | **H**、**N**、**O** | 极性共价键（N=O、N–O、O–H） | [查看](./12-nitric-acid.md) |
| 氢氧化钠 | NaOH | **Na**、**H**、**O** | 离子键（Na⁺–OH⁻），OH⁻ 内部为共价键 | [查看](./13-sodium-hydroxide.md) |
| 氢氧化钙 | Ca(OH)₂ | **Ca**、**H**、**O** | 离子键（Ca²⁺–OH⁻） | [查看](./14-calcium-hydroxide.md) |
| 氯化钠 | NaCl | **Na**、**Cl** | 离子键 | [查看](./15-sodium-chloride.md) |
| 碳酸钠 | Na₂CO₃ | **Na**、**C**、**O** | 离子键（Na⁺–CO₃²⁻），CO₃²⁻ 内部为共价键（含共振） | [查看](./16-sodium-carbonate.md) |
| 碳酸氢钠 | NaHCO₃ | **Na**、**H**、**C**、**O** | 离子键（Na⁺–HCO₃⁻），HCO₃⁻ 内部为共价键 | [查看](./17-sodium-bicarbonate.md) |
| 氧化钙 | CaO | **Ca**、**O** | 离子键 | [查看](./18-calcium-oxide.md) |
| 氧化铝 | Al₂O₃ | **Al**、**O** | 离子键（Al³⁺–O²⁻），Al–O 有较强共价成分 | [查看](./19-aluminium-oxide.md) |
| 二氧化硅 | SiO₂ | **Si**、**O** | 共价键（Si–O） | [查看](./20-silicon-dioxide.md) |
| 碳酸钙 | CaCO₃ | **Ca**、**C**、**O** | 离子键（Ca²⁺–CO₃²⁻），CO₃²⁻ 内部为共价键 | [查看](./21-calcium-carbonate.md) |
