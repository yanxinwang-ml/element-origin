# 碳酸钠（Na₂CO₃）

## 基本信息

| 项目 | 内容 |
|---|---|
| 中文名 | 碳酸钠 |
| 英文名 | Sodium Carbonate |
| 化学式 | Na₂CO₃ |
| 相对分子质量 | 105.99 g/mol |
| 状态 | 白色粉末（纯碱/苏打），易溶于水，水溶液呈碱性 |
| 组成元素 | **Na**（11 号元素）、**C**（6 号元素）、**O**（8 号元素） |
| 化学键类型 | 离子键（Na⁺–CO₃²⁻），CO₃²⁻ 内部为共价键（含共振） |
| 分子极性 | 离子晶体 |

## 组成方式（原子如何结合）

离子化合物：2 个 Na⁺ 与 CO₃²⁻ 结合；CO₃²⁻ 为平面三角形共振离子。

## 组成原理（为什么这样结合）

- CO₃²⁻ 中碳与三个氧成键：一个 C=O 双键与两个 C–O 单键在三个氧之间共振，三个 C–O 键实际等同（键级约 1.33），呈平面三角形。
- CO₃²⁻ 水解使溶液呈碱性：CO₃²⁻ + H₂O ⇌ HCO₃⁻ + OH⁻，因此纯碱是重要的工业碱源。

## 组成元素的宇宙起源

该物质由以下元素组成，各元素的核合成起源见对应文档：

- [钠（Na）](../elements/011-sodium.md)：原子序数 11，太阳系中的主导来源为「大质量恒星核燃烧/超新星」。
- [碳（C）](../elements/006-carbon.md)：原子序数 6，太阳系中的主导来源为「低质量恒星死亡（AGB 星，s-过程）」。
- [氧（O）](../elements/008-oxygen.md)：原子序数 8，太阳系中的主导来源为「大质量恒星核燃烧/超新星」。

## 出现年代与宇宙纪元

- 元素来自恒星；天然碱湖与沉积矿（如美国 trona 矿，形成于约 5000 万年前）自古存在；工业上索尔维法 1861 年、侯氏制碱法 1943 年。

## 产生方式

- 天然：碱湖蒸发浓缩并吸收 CO₂ 析出天然碱。
- 工业：索尔维/侯氏制碱——NaCl + NH₃ + CO₂ + H₂O → NaHCO₃↓ + NH₄Cl，再加热分解 NaHCO₃ 得 Na₂CO₃。

## 常见制取

- 侯氏制碱法（联合制碱）：先制 NaHCO₃：NaCl + NH₃ + CO₂ + H₂O → NaHCO₃↓ + NH₄Cl，再加热分解：2NaHCO₃ ——加热→ Na₂CO₃ + H₂O + CO₂↑。

## 主要用途

- 玻璃制造
- 洗涤剂与造纸
- 面食加工（中和酸）
