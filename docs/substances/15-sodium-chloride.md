# 氯化钠（NaCl）

## 基本信息

| 项目 | 内容 |
|---|---|
| 中文名 | 氯化钠 |
| 英文名 | Sodium Chloride |
| 化学式 | NaCl |
| 相对分子质量 | 58.44 g/mol |
| 状态 | 白色晶体（食盐主要成分），易溶于水 |
| 组成元素 | **Na**（11 号元素）、**Cl**（17 号元素） |
| 化学键类型 | 离子键 |
| 分子极性 | 离子晶体 |

## 组成方式（原子如何结合）

离子晶体：Na⁺ 与 Cl⁻ 交替排列，形成面心立方晶格（每个 Na⁺ 周围 6 个 Cl⁻，反之亦然）。

## 组成原理（为什么这样结合）

- 钠失 1 个电子成为 Na⁺，氯得 1 个电子成为 Cl⁻，两者因库仑引力结合；正负离子在三维空间周期排列，晶格能很高，使 NaCl 熔点高、硬度较大。
- 溶于水时离子被水分子包围而分离，溶液能导电；熔融态也能导电（工业电解熔融 NaCl 制钠：2NaCl ——电解熔融→ 2Na + Cl₂↑）。

## 组成元素的宇宙起源

该物质由以下元素组成，各元素的核合成起源见对应文档：

- [钠（Na）](../elements/011-sodium.md)：原子序数 11，太阳系中的主导来源为「大质量恒星核燃烧/超新星」。
- [氯（Cl）](../elements/017-chlorine.md)：原子序数 17，太阳系中的主导来源为「大质量恒星核燃烧/超新星」。

## 出现年代与宇宙纪元

- 元素钠（恒星碳燃烧）与氯（超新星）分别来自恒星；地球海洋自约 40 亿年前形成后，蒸发结晶出石盐矿床；人类自史前即开采食盐。

## 产生方式

- 行星尺度：海洋/盐湖中 Na⁺ 与 Cl⁻ 蒸发浓缩结晶成石盐（蒸发岩）。
- 人类：海水晒盐、盐矿开采与提纯。

## 常见制取

- 海水晒盐（蒸发结晶）或盐矿开采提纯。
- 工业以 NaCl 为原料进行氯碱电解、制钠等。

## 主要用途

- 食盐与食品保鲜
- 氯碱工业原料
- 道路融雪
