# 氢氧化钠（NaOH）

## 基本信息

| 项目 | 内容 |
|---|---|
| 中文名 | 氢氧化钠 |
| 英文名 | Sodium Hydroxide |
| 化学式 | NaOH |
| 相对分子质量 | 40.00 g/mol |
| 状态 | 白色固体，易潮解，水溶液为强碱 |
| 组成元素 | **Na**（11 号元素）、**H**（1 号元素）、**O**（8 号元素） |
| 化学键类型 | 离子键（Na⁺–OH⁻），OH⁻ 内部为共价键 |
| 分子极性 | 离子晶体 |

## 组成方式（原子如何结合）

离子化合物：Na⁺ 与 OH⁻（O–H 共价键）通过离子键结合。

## 组成原理（为什么这样结合）

- 钠原子（1 个价电子）极易失去电子形成 Na⁺，氧原子倾向得电子或与氢共用电子形成 OH⁻（羟基）；正负离子靠静电引力（离子键）结合。
- NaOH 在水中完全电离：NaOH → Na⁺ + OH⁻，因此是强碱；浓溶液对皮肤、玻璃有强腐蚀性。

## 组成元素的宇宙起源

该物质由以下元素组成，各元素的核合成起源见对应文档：

- [钠（Na）](../elements/011-sodium.md)：原子序数 11，太阳系中的主导来源为「大质量恒星核燃烧/超新星」。
- [氢（H）](../elements/001-hydrogen.md)：原子序数 1，太阳系中的主导来源为「大爆炸核合成」。
- [氧（O）](../elements/008-oxygen.md)：原子序数 8，太阳系中的主导来源为「大质量恒星核燃烧/超新星」。

## 常见制取

- 氯碱工业（电解饱和食盐水）：2NaCl + 2H₂O ——通电→ 2NaOH + H₂↑ + Cl₂↑。
- 化学法：Na₂CO₃ + Ca(OH)₂ → CaCO₃↓ + 2NaOH。

## 主要用途

- 制皂与造纸
- 化工与石油加工
- 实验室强碱
