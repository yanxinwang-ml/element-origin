# 二氧化碳（CO₂）

## 基本信息

| 项目 | 内容 |
|---|---|
| 中文名 | 二氧化碳 |
| 英文名 | Carbon Dioxide |
| 化学式 | CO₂ |
| 相对分子质量 | 44.01 g/mol |
| 状态 | 常温下为无色无味气体，可溶于水；固态称干冰 |
| 组成元素 | **C**（6 号元素）、**O**（8 号元素） |
| 化学键类型 | 极性共价键（C=O），分子整体对称 |
| 分子极性 | 非极性分子 |

## 组成方式（原子如何结合）

直线形分子，结构式 O=C=O，两个 C=O 双键对称排列。

## 组成原理（为什么这样结合）

- 碳原子外层有 4 个电子，与两个氧原子各形成双键（共用两对电子），使碳和两个氧都满足八隅体。
- 两个 C=O 键方向相反、偶极相互抵消，因此分子整体为非极性；CO₂ 可溶于水生成碳酸 H₂CO₃（弱酸）。

## 组成元素的宇宙起源

该物质由以下元素组成，各元素的核合成起源见对应文档：

- [碳（C）](../elements/006-carbon.md)：原子序数 6，太阳系中的主导来源为「低质量恒星死亡（AGB 星，s-过程）」。
- [氧（O）](../elements/008-oxygen.md)：原子序数 8，太阳系中的主导来源为「大质量恒星核燃烧/超新星」。

## 出现年代与宇宙纪元

- 元素碳（约 136–130 亿年前恒星合成）与氧结合后，CO₂ 在行星大气和星际冰中广泛存在；地球原始大气（约 45 亿年前）富含 CO₂，火山持续向大气排放。

## 产生方式

- 燃烧/氧化：C + O₂ ——点燃→ CO₂（恒星核燃烧、森林火灾、化石燃料燃烧）。
- 火山与热分解：CaCO₃ ——高温→ CaO + CO₂↑；生物呼吸作用。
- 星际/低温：CO₂ 以干冰形式存在于星际尘埃表面。

## 常见制取

- 燃烧：C + O₂ ——点燃→ CO₂；含碳燃料充分燃烧的主要产物。
- 实验室：CaCO₃ + 2HCl → CaCl₂ + H₂O + CO₂↑。
- 工业/高温：CaCO₃ ——高温→ CaO + CO₂↑；发酵与呼吸作用也产生 CO₂。

## 主要用途

- 灭火器
- 碳酸饮料与干冰
- 光合作用原料、温室气体
