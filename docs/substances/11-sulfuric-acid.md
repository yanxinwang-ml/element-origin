# 硫酸（H₂SO₄）

## 基本信息

| 项目 | 内容 |
|---|---|
| 中文名 | 硫酸 |
| 英文名 | Sulfuric Acid |
| 化学式 | H₂SO₄ |
| 相对分子质量 | 98.08 g/mol |
| 状态 | 纯品为无色油状液体，难挥发，具强吸水性 |
| 组成元素 | **H**（1 号元素）、**S**（16 号元素）、**O**（8 号元素） |
| 化学键类型 | 极性共价键（S=O、S–O、O–H） |
| 分子极性 | 极性分子 |

## 组成方式（原子如何结合）

硫原子为中心四面体：两个 S=O 双键 + 两个 S–OH 单键。

## 组成原理（为什么这样结合）

- 硫原子（6 个价电子）与 4 个氧原子成键：2 个双键、2 个单键（后者再连氢），形成稳定的四面体结构，硫可扩展八隅体（超价）。
- 两个羟基氢在水中完全电离，第一步 H₂SO₄ → H⁺ + HSO₄⁻（强），第二步 HSO₄⁻ ⇌ H⁺ + SO₄²⁻；浓硫酸还有强吸水性和脱水性。

## 组成元素的宇宙起源

该物质由以下元素组成，各元素的核合成起源见对应文档：

- [氢（H）](../elements/001-hydrogen.md)：原子序数 1，太阳系中的主导来源为「大爆炸核合成」。
- [硫（S）](../elements/016-sulfur.md)：原子序数 16，太阳系中的主导来源为「大质量恒星核燃烧/超新星」。
- [氧（O）](../elements/008-oxygen.md)：原子序数 8，太阳系中的主导来源为「大质量恒星核燃烧/超新星」。

## 常见制取

- 接触法：S（或 FeS₂ 焙烧）→ SO₂ →（V₂O₅ 催化、约 450°C）SO₃ → 溶于浓硫酸再稀释得 H₂SO₄。

## 主要用途

- 化肥（磷肥）与化工原料
- 铅蓄电池电解质
- 干燥剂与脱水剂
