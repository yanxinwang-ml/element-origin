# 二氧化硅（SiO₂）

## 基本信息

| 项目 | 内容 |
|---|---|
| 中文名 | 二氧化硅 |
| 英文名 | Silicon Dioxide |
| 化学式 | SiO₂ |
| 相对分子质量 | 60.08 g/mol |
| 状态 | 常温下为固体（石英、砂子），熔点很高 |
| 组成元素 | **Si**（14 号元素）、**O**（8 号元素） |
| 化学键类型 | 共价键（Si–O） |
| 分子极性 | 原子晶体（不导电） |

## 组成方式（原子如何结合）

共价晶体（原子晶体）：每个 Si 与 4 个 O 以共价键相连，每个 O 连接 2 个 Si，形成三维空间网络（无独立分子）。

## 组成原理（为什么这样结合）

- 硅（4 个价电子）与氧（6 个价电子）通过共价键连接，Si 满足八隅体（与 4 个 O 成 4 个单键），O 与两个 Si 成键也满足八隅体。
- 整个晶体是一个巨型分子，Si–O 键能高，因此 SiO₂ 硬度大、熔点高；它不与水反应，但能与强碱或氢氟酸反应。

## 组成元素的宇宙起源

该物质由以下元素组成，各元素的核合成起源见对应文档：

- [硅（Si）](../elements/014-silicon.md)：原子序数 14，太阳系中的主导来源为「大质量恒星核燃烧/超新星」。
- [氧（O）](../elements/008-oxygen.md)：原子序数 8，太阳系中的主导来源为「大质量恒星核燃烧/超新星」。

## 出现年代与宇宙纪元

- 元素硅来自恒星氧燃烧（约 136 亿年前）；SiO₂ 是星际尘埃的重要组分（约 130 亿年前起）；地球岩石圈自约 45 亿年前形成即富含石英等 SiO₂ 矿物。

## 产生方式

- 恒星/超新星：硅与氧在冷却的恒星抛出物中凝聚成硅酸盐尘埃（星际尘埃的主要组分）。
- 地质：岩浆结晶出石英、砂岩沉积；人类从沙和石英中提纯 SiO₂ 制玻璃、光纤。

## 常见制取

- 硅燃烧：Si + O₂ ——高温→ SiO₂。
- 自然界大量存在（沙、石英、水晶），工业上用于制玻璃与提纯单质硅（SiO₂ + 2C ——高温→ Si + 2CO↑）。

## 主要用途

- 玻璃与光纤原料
- 集成电路硅片原料
- 石英钟与耐火材料
