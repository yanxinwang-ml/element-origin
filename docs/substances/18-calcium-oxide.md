# 氧化钙（CaO）

## 基本信息

| 项目 | 内容 |
|---|---|
| 中文名 | 氧化钙 |
| 英文名 | Calcium Oxide |
| 化学式 | CaO |
| 相对分子质量 | 56.08 g/mol |
| 状态 | 白色块状固体（生石灰），遇水剧烈放热 |
| 组成元素 | **Ca**（20 号元素）、**O**（8 号元素） |
| 化学键类型 | 离子键 |
| 分子极性 | 离子晶体 |

## 组成方式（原子如何结合）

离子晶体：Ca²⁺ 与 O²⁻ 以离子键结合，岩盐型结构。

## 组成原理（为什么这样结合）

- 钙失去 2 个电子成 Ca²⁺，氧得到 2 个电子成 O²⁻，正负离子静电结合形成稳定晶格；O²⁻ 的强碱性使 CaO 为碱性氧化物。
- 与水反应放热：CaO + H₂O → Ca(OH)₂（放热约 65 kJ/mol），是“生石灰消化”的原理。

## 组成元素的宇宙起源

该物质由以下元素组成，各元素的核合成起源见对应文档：

- [钙（Ca）](../elements/020-calcium.md)：原子序数 20，太阳系中的主导来源为「大质量恒星核燃烧/超新星」。
- [氧（O）](../elements/008-oxygen.md)：原子序数 8，太阳系中的主导来源为「大质量恒星核燃烧/超新星」。

## 出现年代与宇宙纪元

- 元素钙来自恒星；CaO 由人类高温煅烧石灰石制取，石灰使用史可追溯至新石器时代（约 7000–9000 年前），是最早的“人造材料”之一；自然界仅少量以矿物存在。

## 产生方式

- 高温煅烧：CaCO₃ ——高温→ CaO + CO₂↑（人类自新石器时代即掌握此工艺）。

## 常见制取

- 高温煅烧石灰石：CaCO₃ ——高温→ CaO + CO₂↑。

## 主要用途

- 建筑材料（水泥、石灰浆）
- 干燥剂
- 炼钢造渣
