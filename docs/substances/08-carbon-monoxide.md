# 一氧化碳（CO）

## 基本信息

| 项目 | 内容 |
|---|---|
| 中文名 | 一氧化碳 |
| 英文名 | Carbon Monoxide |
| 化学式 | CO |
| 相对分子质量 | 28.01 g/mol |
| 状态 | 常温下为无色无味气体，有毒（与血红蛋白结合） |
| 组成元素 | **C**（6 号元素）、**O**（8 号元素） |
| 化学键类型 | 极性共价键（C≡O） |
| 分子极性 | 极性很弱的极性分子 |

## 组成方式（原子如何结合）

直线形分子，结构式 C≡O，碳氧之间为三键（含一个配位键），碳端保留 1 对孤对电子。

## 组成原理（为什么这样结合）

- 碳与氧各提供部分电子形成三键，使两者都满足八隅体；碳端的孤对电子使 CO 可作配体（如与血红蛋白中的 Fe²⁺ 结合）。
- CO 是碳不完全燃烧的产物，具有较强的还原性，可将金属氧化物还原为金属。

## 组成元素的宇宙起源

该物质由以下元素组成，各元素的核合成起源见对应文档：

- [碳（C）](../elements/006-carbon.md)：原子序数 6，太阳系中的主导来源为「低质量恒星死亡（AGB 星，s-过程）」。
- [氧（O）](../elements/008-oxygen.md)：原子序数 8，太阳系中的主导来源为「大质量恒星核燃烧/超新星」。

## 出现年代与宇宙纪元

- CO 是宇宙中最早形成的分子之一：2018 年 ALMA 在约 128 亿年前的星系中探测到 CO，它也是星际介质中最丰富的含碳分子。

## 产生方式

- 星际碰撞反应：C⁺ + OH → CO + H⁺，以及 C + O → CO（原子碰撞结合）。
- 不完全燃烧：2C + O₂ ——氧气不足→ 2CO；恒星大气与超新星抛射物中的碳氧结合也生成 CO。

## 常见制取

- 不完全燃烧：2C + O₂ ——氧气不足→ 2CO。
- 工业：C + H₂O ——高温→ CO + H₂（水煤气）；HCOOH ——浓硫酸加热→ CO↑ + H₂O。

## 主要用途

- 冶炼金属的还原剂（高炉炼铁）
- 合成气（与 H₂ 混合）原料
- 燃料（需注意通风防中毒）
