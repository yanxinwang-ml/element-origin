# 氧气（O₂）

## 基本信息

| 项目 | 内容 |
|---|---|
| 中文名 | 氧气 |
| 英文名 | Oxygen |
| 化学式 | O₂ |
| 相对分子质量 | 32.00 g/mol |
| 状态 | 常温下为无色、无味气体，微溶于水 |
| 组成元素 | **O**（8 号元素） |
| 化学键类型 | 非极性共价键（O=O 双键） |
| 分子极性 | 非极性分子 |

## 组成方式（原子如何结合）

双原子分子，结构式 O=O，氧原子间以双键相连（实际为三线态，有两个未成对电子，具顺磁性）。

## 组成原理（为什么这样结合）

- 每个氧原子外层有 6 个电子，两个氧原子各提供 2 个电子形成两对共用电子对（双键），使每个氧都满足八隅体，且各自保留 2 对孤对电子。
- 分子轨道理论还表明 O₂ 有 2 个未成对电子，因此氧气具有顺磁性，可被液氧磁化这一性质证实。

## 组成元素的宇宙起源

该物质由以下元素组成，各元素的核合成起源见对应文档：

- [氧（O）](../elements/008-oxygen.md)：原子序数 8，太阳系中的主导来源为「大质量恒星核燃烧/超新星」。

## 出现年代与宇宙纪元

- 元素层面：氧原子诞生于约 136 亿年前第一代大质量恒星的氦燃烧（¹²C + ⁴He → ¹⁶O），并随超新星抛入星际空间。
- 分子层面：星际分子云中的 O₂ 极其稀少（2011 年赫歇尔望远镜才首次确认猎户座分子云中的 O₂）；地球大气中氧气大量出现，是在约 24 亿年前的“大氧化事件”（蓝细菌光合作用）之后。

## 产生方式

- 恒星核合成：氧原子由大质量恒星氦燃烧生成并随超新星抛射；但低温星际环境中的氧多以水冰、硅酸盐尘等形式存在，很少直接成 O₂。
- 光合作用：6CO₂ + 6H₂O →（光）C₆H₁₂O₆ + 6O₂——地球大气氧气的主要来源（大氧化事件）。
- 光解：紫外线把 H₂O、CO₂ 分解出少量 O₂；实验室/工业用电解水、H₂O₂ 分解、空气分馏。

## 常见制取

- 实验室：2H₂O₂ ——MnO₂催化→ 2H₂O + O₂↑；2KMnO₄ ——加热→ K₂MnO₄ + MnO₂ + O₂↑；2KClO₃ ——MnO₂加热→ 2KCl + 3O₂↑。
- 电解水：2H₂O ——通电→ 2H₂↑ + O₂↑。
- 工业：空气液化后分馏（利用氮、氧沸点不同）或膜分离法。

## 主要用途

- 呼吸与医疗供氧
- 助燃（炼钢、焊接、火箭）
- 废水处理与氧化工艺
