# 硝酸（HNO₃）

## 基本信息

| 项目 | 内容 |
|---|---|
| 中文名 | 硝酸 |
| 英文名 | Nitric Acid |
| 化学式 | HNO₃ |
| 相对分子质量 | 63.01 g/mol |
| 状态 | 纯品为无色液体，见光或受热分解，具强氧化性 |
| 组成元素 | **H**（1 号元素）、**N**（7 号元素）、**O**（8 号元素） |
| 化学键类型 | 极性共价键（N=O、N–O、O–H） |
| 分子极性 | 极性分子 |

## 组成方式（原子如何结合）

平面三角形：氮为中心，两个 N=O 双键 + 一个 N–OH 单键。

## 组成原理（为什么这样结合）

- 氮原子以 sp² 杂化与 3 个氧成键（两个双键、一个单键），剩余 p 轨道参与形成大π键，结构为平面三角形。
- 羟基氢完全电离，HNO₃ 是强酸；硝酸中氮为 +5 价（最高价态），因此硝酸具有强氧化性，稀硝酸与浓硝酸氧化能力表现不同。

## 组成元素的宇宙起源

该物质由以下元素组成，各元素的核合成起源见对应文档：

- [氢（H）](../elements/001-hydrogen.md)：原子序数 1，太阳系中的主导来源为「大爆炸核合成」。
- [氮（N）](../elements/007-nitrogen.md)：原子序数 7，太阳系中的主导来源为「低质量恒星死亡（AGB 星，s-过程）」。
- [氧（O）](../elements/008-oxygen.md)：原子序数 8，太阳系中的主导来源为「大质量恒星核燃烧/超新星」。

## 常见制取

- 奥斯特瓦尔德（Ostwald）法：NH₃ 催化氧化 → NO → NO₂ → 与水反应：3NO₂ + H₂O → 2HNO₃ + NO。

## 主要用途

- 氮肥（硝酸铵）原料
- 炸药（如 TNT 需用混酸硝化）
- 金属酸洗与化工
