# 氢气（H₂）

## 基本信息

| 项目 | 内容 |
|---|---|
| 中文名 | 氢气 |
| 英文名 | Hydrogen |
| 化学式 | H₂ |
| 相对分子质量 | 2.016 g/mol |
| 状态 | 常温下为无色、无味气体，密度最小 |
| 组成元素 | **H**（1 号元素） |
| 化学键类型 | 非极性共价键（H–H） |
| 分子极性 | 非极性分子 |

## 组成方式（原子如何结合）

双原子分子，结构式 H–H，两个氢原子以单键相连。

## 组成原理（为什么这样结合）

- 每个氢原子只有 1 个电子，两个氢原子各贡献 1 个电子形成一对共用电子对，使每个氢都达到类似氦的 2 电子稳定结构。
- H₂ 分子比两个孤立的氢原子能量更低（键能约 436 kJ/mol），因此自然界中氢通常以 H₂ 而非单原子形式存在。

## 组成元素的宇宙起源

该物质由以下元素组成，各元素的核合成起源见对应文档：

- [氢（H）](../elements/001-hydrogen.md)：原子序数 1，太阳系中的主导来源为「大爆炸核合成」。

## 常见制取

- 活泼金属与酸：Zn + 2HCl → ZnCl₂ + H₂↑（实验室常用）。
- 电解水：2H₂O ——通电→ 2H₂↑ + O₂↑。
- 工业水煤气：C + H₂O ——高温→ CO + H₂。

## 主要用途

- 合成氨（Haber 法）原料
- 加氢反应与还原剂
- 燃料电池与清洁能源
