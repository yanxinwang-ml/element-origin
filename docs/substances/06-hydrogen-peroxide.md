# 过氧化氢（H₂O₂）

## 基本信息

| 项目 | 内容 |
|---|---|
| 中文名 | 过氧化氢 |
| 英文名 | Hydrogen Peroxide |
| 化学式 | H₂O₂ |
| 相对分子质量 | 34.01 g/mol |
| 状态 | 纯品为无色粘稠液体，水溶液俗称双氧水 |
| 组成元素 | **H**（1 号元素）、**O**（8 号元素） |
| 化学键类型 | 极性共价键（O–H、O–O） |
| 分子极性 | 极性分子 |

## 组成方式（原子如何结合）

开链结构 H–O–O–H，O–O 单键连接两个 O–H。

## 组成原理（为什么这样结合）

- 每个氧原子与一个氢和一个氧各成键，满足八隅体；分子中氧的氧化态为 −1（介于 O₂ 的 0 与 H₂O 的 −2 之间），因此不稳定，容易发生歧化分解。
- 分解反应：2H₂O₂ → 2H₂O + O₂↑（放热，MnO₂ 等可催化）。

## 组成元素的宇宙起源

该物质由以下元素组成，各元素的核合成起源见对应文档：

- [氢（H）](../elements/001-hydrogen.md)：原子序数 1，太阳系中的主导来源为「大爆炸核合成」。
- [氧（O）](../elements/008-oxygen.md)：原子序数 8，太阳系中的主导来源为「大质量恒星核燃烧/超新星」。

## 出现年代与宇宙纪元

- 星际纪元：太阳系形成前（约 46 亿年前）的分子云冰粒上就存在 H₂O₂（2011 年赫歇尔望远镜首次在星际介质中直接探测到）。
- 地球：大气中仅痕量存在，主要作为工业化学品（19 世纪起规模化生产）。

## 产生方式

- 星际：水冰被宇宙线/紫外线辐照，或 HO₂ + H₂ → H₂O₂ + H 等冰面与气相反应生成。
- 工业：硫酸氢铵电解后水解、BaO₂ + H₂SO₄ → BaSO₄↓ + H₂O₂。

## 常见制取

- BaO₂ + H₂SO₄ → BaSO₄↓ + H₂O₂（实验室经典方法）。
- 工业：硫酸氢铵电解后水解制得。

## 主要用途

- 伤口消毒
- 漂白与去污
- 环保氧化剂
