# 碳酸氢钠（NaHCO₃）

## 基本信息

| 项目 | 内容 |
|---|---|
| 中文名 | 碳酸氢钠 |
| 英文名 | Sodium Bicarbonate |
| 化学式 | NaHCO₃ |
| 相对分子质量 | 84.01 g/mol |
| 状态 | 白色细小晶体（小苏打），可溶于水，水溶液呈弱碱性 |
| 组成元素 | **Na**（11 号元素）、**H**（1 号元素）、**C**（6 号元素）、**O**（8 号元素） |
| 化学键类型 | 离子键（Na⁺–HCO₃⁻），HCO₃⁻ 内部为共价键 |
| 分子极性 | 离子晶体 |

## 组成方式（原子如何结合）

离子化合物：Na⁺ 与 HCO₃⁻ 结合；HCO₃⁻ 含 C=O、C–O 与 O–H。

## 组成原理（为什么这样结合）

- HCO₃⁻ 是碳酸的酸式根：碳酸 H₂CO₃ 失去一个 H⁺ 后得到 HCO₃⁻，再失去才得 CO₃²⁻，因此 NaHCO₃ 既能与酸反应放出 CO₂，也能与碱反应。
- 受热分解：2NaHCO₃ ——加热→ Na₂CO₃ + H₂O + CO₂↑，这也是小苏打作膨松剂和灭火剂成分的原理。

## 组成元素的宇宙起源

该物质由以下元素组成，各元素的核合成起源见对应文档：

- [钠（Na）](../elements/011-sodium.md)：原子序数 11，太阳系中的主导来源为「大质量恒星核燃烧/超新星」。
- [氢（H）](../elements/001-hydrogen.md)：原子序数 1，太阳系中的主导来源为「大爆炸核合成」。
- [碳（C）](../elements/006-carbon.md)：原子序数 6，太阳系中的主导来源为「低质量恒星死亡（AGB 星，s-过程）」。
- [氧（O）](../elements/008-oxygen.md)：原子序数 8，太阳系中的主导来源为「大质量恒星核燃烧/超新星」。

## 出现年代与宇宙纪元

- 天然存在于含碳酸氢根的热泉/碱湖（如天然小苏打矿 nahcolite）；工业上 19 世纪随索尔维法制碱作为中间产物普及。

## 产生方式

- 天然：CO₂ 溶于含钠离子的水，蒸发析出碳酸氢钠（热泉/碱湖）。
- 工业：索尔维/侯氏制碱法的中间产物（低温下 NaHCO₃ 溶解度小而析出）。

## 常见制取

- 侯氏/索尔维制碱法中间产物：NaCl + NH₃ + CO₂ + H₂O → NaHCO₃↓ + NH₄Cl（低温下溶解度小而析出）。

## 主要用途

- 烘焙膨松剂
- 中和胃酸（抗酸药）
- 泡沫灭火器成分
