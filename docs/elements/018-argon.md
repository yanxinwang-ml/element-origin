# 氩 Argon（Ar）— 原子序数 18

## 基本信息

| 项目 | 内容 |
|---|---|
| 原子序数 | 18 |
| 符号 | Ar |
| 中文名 | 氩 |
| 英文名 | Argon |
| 发现 | Rayleigh and Ramsay（1894） |
| 太阳系丰度 | log ε ≈ 6.55（以氢 = 12 为基准） |

## 起源概述

该元素在太阳系中主要由「大质量恒星核燃烧/超新星」产生（约 56%）。大质量恒星内部逐级燃烧氢、氦、碳、氖、氧、硅直到铁；坍缩超新星把产物抛回星际空间。 其余来自：「白矮星爆发（Ia 型超新星）」（约 44%）。

### 路径 2：白矮星爆发（Ia 型超新星）（占比 44%）

| 项目 | 内容 |

| 主要反应 | 白矮星热核爆炸：爆炸性硅燃烧 → 铁族（⁵⁶Ni → ⁵⁶Co → ⁵⁶Fe） |
| 动画配方 | `explosion:Si28->Ar36` |

**核素变化链：**

1. ²⁸Si(14p+14n) →（爆炸性核合成，示意）→ ³⁶Ar(18p+18n)

白矮星吸积或并合触发碳氧热核爆炸（Ia 型超新星），主要生产铁族元素（Cr、Mn、Fe、Ni 等）。
