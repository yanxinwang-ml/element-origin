| 中文名 | 锶 |

| 太阳系丰度 | log ε ≈ 2.95（以氢 = 12 为基准） |

## 起源概述

该元素在太阳系中主要由「低质量恒星死亡（AGB 星，s-过程）」产生（约 87%）。低质量恒星演化到渐近巨星分支（AGB）时，慢中子俘获（s-过程）把种子核逐步推向锶、钡、铅等重元素，星风将产物吹回星际空间。 其余来自：「大质量恒星核燃烧/超新星」（约 13%）。
