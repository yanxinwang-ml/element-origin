## 起源概述

该元素在太阳系中主要由「白矮星爆发（Ia 型超新星）」产生（约 70%）。白矮星吸积或并合触发碳氧热核爆炸（Ia 型超新星），主要生产铁族元素（Cr、Mn、Fe、Ni 等）。 其余来自：「大质量恒星核燃烧/超新星」（约 30%）。

### 路径 2：大质量恒星核燃烧/超新星（占比 30%）

| 项目 | 内容 |
|---|---|
| 生成场所 | 大质量恒星内部 / 坍缩超新星 |
| 过程 | 恒星核燃烧 / 爆炸核合成 |
| 占太阳系来源 | 30% |
| 主要反应 | 爆炸核合成：⁵⁸Ni / ⁶²Ni |

**核素变化链：**

1. ⁴He(2p+2n) + ⁵⁶Fe(26p+30n) → ⁶⁰Ni(28p+32n)
