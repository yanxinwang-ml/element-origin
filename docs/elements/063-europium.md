# 铕 Europium（Eu）— 原子序数 63

## 基本信息

| 项目 | 内容 |
|---|---|
| 原子序数 | 63 |
| 符号 | Eu |
| 中文名 | 铕 |
| 英文名 | Europium |
| 发现 | Demarcay（1901） |
| 太阳系丰度 | log ε ≈ 0.58（以氢 = 12 为基准） |

## 起源概述

铕是典型的 r-过程元素（约 95% 来自中子星并合），常被天文学家用来衡量 r-过程的贡献。

## 生成路径（2 条）

### 路径 1：中子星并合（r-过程）（占比 95%）

| 项目 | 内容 |
|---|---|
| 生成场所 | 中子星并合（千新星） |
| 过程 | r-过程（快中子俘获） |
| 占太阳系来源 | 95% |
| 主要反应 | r-过程：种子核快中子俘获 → ¹⁵¹Eu/¹⁵³Eu |
| 动画配方 | `rproc:Fe56->Eu153` |

**核素变化链：**

1. ⁵⁶Fe(26p+30n)(种子) → 快中子俘获 ×97 → β⁻ 衰变 ×37 → ¹⁵³Eu(63p+90n)（示意链）

两颗中子星并合时极短时间内连续俘获中子（r-过程），生成金、铂、铀等重元素。2017 年 GW170817 千新星首次直接观测证实。

### 路径 2：低质量恒星死亡（AGB 星，s-过程）（占比 5%）

| 项目 | 内容 |
|---|---|
| 生成场所 | AGB 星（低质量恒星晚期） |
| 过程 | s-过程（慢中子俘获） |
| 占太阳系来源 | 5% |
| 主要反应 | s-过程：种子核（Fe/Sr/Zr 等）逐次慢中子俘获，两次俘获间 β⁻ 衰变，沿 s-路径到达该元素 |
| 动画配方 | `sproc:Fe56->Eu153` |

**核素变化链：**

1. ⁵⁶Fe(26p+30n)(种子) → 慢中子俘获 ×97 → β⁻ 衰变 ×37 → ¹⁵³Eu(63p+90n)（示意链）

低质量恒星演化到渐近巨星分支（AGB）时，慢中子俘获（s-过程）把种子核逐步推向锶、钡、铅等重元素，星风将产物吹回星际空间。
