# 氦 Helium（He）— 原子序数 2

## 基本信息

| 项目 | 内容 |
|---|---|
| 原子序数 | 2 |
| 符号 | He |
| 中文名 | 氦 |
| 英文名 | Helium |
| 发现 | Janssen（1868） |
| 太阳系丰度 | log ε ≈ 10.99（以氢 = 12 为基准） |

## 起源概述

约 91% 的氦来自大爆炸；恒星聚变也持续生产新的氦（氦在宇宙中质量占比约 25%）。

## 生成路径（3 条）

### 路径 1：大爆炸核合成（占比 91%）

| 项目 | 内容 |
|---|---|
| 生成场所 | 宇宙大爆炸（t ≈ 3–20 分钟） |
| 过程 | 大爆炸核合成（BBN） |
| 占太阳系来源 | 91% |
| 主要反应 | p + n → d；d + d → ⁴He（另有 ³He + n → ⁴He） |
| 动画配方 | `fusion:p+n->D2;fusion:D2+D2->He4` |

**核素变化链：**

1. p(1p+0n) + n(0p+1n) → ²D
2. ²D + ²D → ⁴He(2p+2n)

宇宙诞生后最初约 3–20 分钟内，质子和中子结合成氢、氦及微量锂。

### 路径 2：大质量恒星核燃烧/超新星（占比 5%）

| 项目 | 内容 |
|---|---|
| 生成场所 | 大质量恒星内部 / 坍缩超新星 |
| 过程 | 恒星核燃烧 / 爆炸核合成 |
| 占太阳系来源 | 5% |
| 主要反应 | 恒星逐级核燃烧 / 超新星爆炸核合成 → 铁族 |
| 动画配方 | `fusion:H1+H1->D2;fusion:H1+D2->He3;fusion:He3+He3->He4+2p` |

**核素变化链：**

1. ¹H(1p+0n) + ¹H(1p+0n) → ²D
2. ¹H(1p+0n) + ²D → ³He(2p+1n)
3. ³He(2p+1n) + ³He(2p+1n) → ⁴He(2p+2n) + 2×p

大质量恒星内部逐级燃烧氢、氦、碳、氖、氧、硅直到铁；坍缩超新星把产物抛回星际空间。

### 路径 3：低质量恒星死亡（AGB 星，s-过程）（占比 4%）

| 项目 | 内容 |
|---|---|
| 生成场所 | AGB 星（低质量恒星晚期） |
| 过程 | s-过程（慢中子俘获） |
| 占太阳系来源 | 4% |
| 主要反应 | s-过程：种子核（Fe/Sr/Zr 等）逐次慢中子俘获，两次俘获间 β⁻ 衰变，沿 s-路径到达该元素 |
| 动画配方 | `fusion:H1+H1->D2;fusion:H1+D2->He3;fusion:He3+He3->He4+2p` |

**核素变化链：**

1. ¹H(1p+0n) + ¹H(1p+0n) → ²D
2. ¹H(1p+0n) + ²D → ³He(2p+1n)
3. ³He(2p+1n) + ³He(2p+1n) → ⁴He(2p+2n) + 2×p

低质量恒星演化到渐近巨星分支（AGB）时，慢中子俘获（s-过程）把种子核逐步推向锶、钡、铅等重元素，星风将产物吹回星际空间。
