## 起源概述

铀是 r-过程产物，由中子星并合产生。其长半衰期使铀成为测年的“时钟”（如地球年龄约 45.6 亿年）。

### 路径 1：中子星并合（r-过程）（占比 100%）

| 项目 | 内容 |
|---|---|
| 生成场所 | 中子星并合（千新星） |
| 过程 | r-过程（快中子俘获） |
| 占太阳系来源 | 100% |
| 主要反应 | r-过程：丰中子前体 β 衰变 → ²³⁵U / ²³⁸U |
| 动画配方 | `rproc:Fe56->U238` |

**核素变化链：**

1. ⁵⁶Fe(26p+30n)(种子) → 快中子俘获 ×182 → β⁻ 衰变 ×66 → ²³⁸U(92p+146n)（示意链）

两颗中子星并合时极短时间内连续俘获中子（r-过程），生成金、铂、铀等重元素。2017 年 GW170817 千新星首次直接观测证实。
