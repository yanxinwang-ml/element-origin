# 铈 Cerium（Ce）— 原子序数 58

## 基本信息

| 项目 | 内容 |
|---|---|
| 原子序数 | 58 |
| 符号 | Ce |
| 中文名 | 铈 |
| 英文名 | Cerium |
| 发现 | Berzelius（1803） |
| 太阳系丰度 | log ε ≈ 1.66（以氢 = 12 为基准） |

## 起源概述

该元素在太阳系中主要由「低质量恒星死亡（AGB 星，s-过程）」产生（约 76%）。低质量恒星演化到渐近巨星分支（AGB）时，慢中子俘获（s-过程）把种子核逐步推向锶、钡、铅等重元素，星风将产物吹回星际空间。 其余来自：「中子星并合（r-过程）」（约 24%）。

低质量恒星演化到渐近巨星分支（AGB）时，慢中子俘获（s-过程）把种子核逐步推向锶、钡、铅等重元素，星风将产物吹回星际空间。

### 路径 2：中子星并合（r-过程）（占比 24%）

| 项目 | 内容 |
|---|---|
| 生成场所 | 中子星并合（千新星） |
| 过程 | r-过程（快中子俘获） |
| 占太阳系来源 | 24% |
| 主要反应 | r-过程：种子核在 <1 s 内连续俘获数十个中子，生成丰中子核后 β⁻ 衰变为该元素 |
| 动画配方 | `rproc:Fe56->Ce140` |

**核素变化链：**

1. ⁵⁶Fe(26p+30n)(种子) → 快中子俘获 ×84 → β⁻ 衰变 ×32 → ¹⁴⁰Ce(58p+82n)（示意链）

两颗中子星并合时极短时间内连续俘获中子（r-过程），生成金、铂、铀等重元素。2017 年 GW170817 千新星首次直接观测证实。
