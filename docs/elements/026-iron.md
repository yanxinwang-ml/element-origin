# 铁 Iron（Fe）— 原子序数 26

## 基本信息

| 项目 | 内容 |
|---|---|
| 原子序数 | 26 |
| 符号 | Fe |
| 中文名 | 铁 |
| 英文名 | Iron |
| 发现 | 古代已知（史前） |
| 太阳系丰度 | log ε ≈ 7.52（以氢 = 12 为基准） |

## 起源概述

铁主要由 Ia 型白矮星爆发贡献（约 2/3），其余来自大质量恒星。铁是核聚变释放能量的“终点”，再往上聚变不再放出能量。

## 生成路径（2 条）

### 路径 1：白矮星爆发（Ia 型超新星）（占比 64%）

| 项目 | 内容 |
|---|---|
| 生成场所 | 白矮星爆发（Ia 型超新星） |
| 过程 | 热核爆炸核合成 |
| 占太阳系来源 | 64% |
| 主要反应 | Ia 型超新星：⁵⁶Ni → ⁵⁶Co → ⁵⁶Fe（衰变链） |
| 动画配方 | `bplus:Ni56->Co56;bplus:Co56->Fe56` |

**核素变化链：**

1. ⁵⁶Ni(28p+28n) → ⁵⁶Co(27p+29n) + e⁺ + ν
2. ⁵⁶Co(27p+29n) → ⁵⁶Fe(26p+30n) + e⁺ + ν

白矮星吸积或并合触发碳氧热核爆炸（Ia 型超新星），主要生产铁族元素（Cr、Mn、Fe、Ni 等）。

### 路径 2：大质量恒星核燃烧/超新星（占比 36%）

| 项目 | 内容 |
|---|---|
| 生成场所 | 大质量恒星内部 / 坍缩超新星 |
| 过程 | 恒星核燃烧 / 爆炸核合成 |
| 占太阳系来源 | 36% |
| 主要反应 | 大质量恒星硅燃烧 + 坍缩超新星爆发核合成 |
| 动画配方 | `fusion:He4+Cr52->Fe56` |

**核素变化链：**

1. ⁴He(2p+2n) + ⁵²Cr(24p+28n) → ⁵⁶Fe(26p+30n)

大质量恒星内部逐级燃烧氢、氦、碳、氖、氧、硅直到铁；坍缩超新星把产物抛回星际空间。
