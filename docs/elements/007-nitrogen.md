# 氮 Nitrogen（N）— 原子序数 7

## 基本信息

| 项目 | 内容 |
|---|---|
| 原子序数 | 7 |
| 符号 | N |
| 中文名 | 氮 |
| 英文名 | Nitrogen |
| 发现 | Rutherford（1772） |
| 太阳系丰度 | log ε ≈ 7.91（以氢 = 12 为基准） |

## 起源概述

氮主要来自 AGB 星的 CNO 循环产物抛射，加上大质量恒星的贡献。

## 生成路径（2 条）

### 路径 1：低质量恒星死亡（AGB 星，s-过程）（占比 75%）

| 项目 | 内容 |
|---|---|
| 生成场所 | AGB 星（低质量恒星晚期） |
| 过程 | s-过程（慢中子俘获） |
| 占太阳系来源 | 75% |
| 主要反应 | CNO 循环产物 ¹⁴N，经第三次 dredge-up 与星风抛射 |
| 动画配方 | `fusion:p+C12->N13;bplus:N13->C13;fusion:p+C13->N14` |

**核素变化链：**

1. p(1p+0n) + ¹²C(6p+6n) → ¹³N(7p+6n)
2. ¹³N(7p+6n) → ¹³C(6p+7n) + e⁺ + ν
3. p(1p+0n) + ¹³C(6p+7n) → ¹⁴N(7p+7n)

低质量恒星演化到渐近巨星分支（AGB）时，慢中子俘获（s-过程）把种子核逐步推向锶、钡、铅等重元素，星风将产物吹回星际空间。

### 路径 2：大质量恒星核燃烧/超新星（占比 25%）

| 项目 | 内容 |
|---|---|
| 生成场所 | 大质量恒星内部 / 坍缩超新星 |
| 过程 | 恒星核燃烧 / 爆炸核合成 |
| 占太阳系来源 | 25% |
| 主要反应 | 氢燃烧 CNO 循环：¹²C(p,γ)¹³N… → ¹⁴N |
| 动画配方 | `fusion:p+C12->N13;bplus:N13->C13;fusion:p+C13->N14` |

**核素变化链：**

1. p(1p+0n) + ¹²C(6p+6n) → ¹³N(7p+6n)
2. ¹³N(7p+6n) → ¹³C(6p+7n) + e⁺ + ν
3. p(1p+0n) + ¹³C(6p+7n) → ¹⁴N(7p+7n)

大质量恒星内部逐级燃烧氢、氦、碳、氖、氧、硅直到铁；坍缩超新星把产物抛回星际空间。
