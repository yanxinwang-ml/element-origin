| 项目 | 内容 |

| 原子序数 | 24 |

| 中文名 | 铬 |

| 发现 | Vauquelin（1797） |
| 太阳系丰度 | log ε ≈ 5.70（以氢 = 12 为基准） |

## 起源概述

该元素在太阳系中主要由「白矮星爆发（Ia 型超新星）」产生（约 77%）。白矮星吸积或并合触发碳氧热核爆炸（Ia 型超新星），主要生产铁族元素（Cr、Mn、Fe、Ni 等）。 其余来自：「大质量恒星核燃烧/超新星」（约 23%）。

白矮星吸积或并合触发碳氧热核爆炸（Ia 型超新星），主要生产铁族元素（Cr、Mn、Fe、Ni 等）。

### 路径 2：大质量恒星核燃烧/超新星（占比 23%）

| 项目 | 内容 |
|---|---|
| 生成场所 | 大质量恒星内部 / 坍缩超新星 |
| 过程 | 恒星核燃烧 / 爆炸核合成 |
| 占太阳系来源 | 23% |
| 主要反应 | 爆炸核合成：⁵²Cr / ⁵³Cr |
| 动画配方 | `fusion:He4+Ti48->Cr52` |

**核素变化链：**

1. ⁴He(2p+2n) + ⁴⁸Ti(22p+26n) → ⁵²Cr(24p+28n)

大质量恒星内部逐级燃烧氢、氦、碳、氖、氧、硅直到铁；坍缩超新星把产物抛回星际空间。
