## 起源概述

氧是宇宙中质量丰度第三的元素（仅次于氢、氦），几乎全部由大质量恒星核燃烧产生，主要路径是氦燃烧中碳-12 俘获 α 粒子生成氧-16。

## 生成路径（1 条）

### 路径 1：大质量恒星核燃烧/超新星（占比 100%）

| 项目 | 内容 |
|---|---|
| 生成场所 | 大质量恒星内部 / 坍缩超新星 |
| 过程 | 恒星核燃烧 / 爆炸核合成 |
| 占太阳系来源 | 100% |
| 主要反应 | 氦燃烧：¹²C + ⁴He → ¹⁶O |
| 动画配方 | `fusion:He4+C12->O16` |

**核素变化链：**

1. ⁴He(2p+2n) + ¹²C(6p+6n) → ¹⁶O(8p+8n)

大质量恒星内部逐级燃烧氢、氦、碳、氖、氧、硅直到铁；坍缩超新星把产物抛回星际空间。
