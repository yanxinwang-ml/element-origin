| 原子序数 | 82 |

| 中文名 | 铅 |

| 太阳系丰度 | log ε ≈ 2.11（以氢 = 12 为基准） |

## 起源概述

该元素在太阳系中主要由「中子星并合（r-过程）」产生（约 53%）。两颗中子星并合时极短时间内连续俘获中子（r-过程），生成金、铂、铀等重元素。2017 年 GW170817 千新星首次直接观测证实。 其余来自：「低质量恒星死亡（AGB 星，s-过程）」（约 47%）。
