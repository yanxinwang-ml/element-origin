## 起源概述

宇宙中质量占比约 75% 的氢几乎全部来自大爆炸。恒星至今仍在把氢聚变成氦，所以宇宙中的“原初氢”在不断被消耗。

## 生成路径（1 条）

### 路径 1：大爆炸核合成（占比 100%）

| 项目 | 内容 |
|---|---|
| 生成场所 | 宇宙大爆炸（t ≈ 3–20 分钟） |
| 过程 | 大爆炸核合成（BBN） |
| 占太阳系来源 | 100% |
| 主要反应 | 原初质子：宇宙冷却后由夸克直接结合而成（无需聚变） |
| 动画配方 | `primordial:H1` |

**核素变化链：**

1. ¹H(1p+0n)（原初质子直接形成，无需反应）

宇宙诞生后最初约 3–20 分钟内，质子和中子结合成氢、氦及微量锂。
