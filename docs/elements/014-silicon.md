# 硅 Silicon（Si）— 原子序数 14

## 基本信息

| 项目 | 内容 |
|---|---|
| 原子序数 | 14 |
| 符号 | Si |
| 中文名 | 硅 |
| 英文名 | Silicon |
| 发现 | Berzelius（1824） |
| 太阳系丰度 | log ε ≈ 7.59（以氢 = 12 为基准） |

## 起源概述

该元素在太阳系中主要由「大质量恒星核燃烧/超新星」产生（约 70%）。大质量恒星内部逐级燃烧氢、氦、碳、氖、氧、硅直到铁；坍缩超新星把产物抛回星际空间。 其余来自：「白矮星爆发（Ia 型超新星）」（约 30%）。

### 路径 1：大质量恒星核燃烧/超新星（占比 70%）

| 项目 | 内容 |
|---|---|
| 生成场所 | 大质量恒星内部 / 坍缩超新星 |
| 过程 | 恒星核燃烧 / 爆炸核合成 |
| 占太阳系来源 | 70% |
| 主要反应 | 氧燃烧：¹⁶O + ¹⁶O → ²⁸Si + ⁴He |
| 动画配方 | `fusion:O16+O16->Si28` |

**核素变化链：**

1. ¹⁶O(8p+8n) + ¹⁶O(8p+8n) → ²⁸Si(14p+14n)

大质量恒星内部逐级燃烧氢、氦、碳、氖、氧、硅直到铁；坍缩超新星把产物抛回星际空间。

### 路径 2：白矮星爆发（Ia 型超新星）（占比 30%）

| 项目 | 内容 |
|---|---|
| 生成场所 | 白矮星爆发（Ia 型超新星） |
| 过程 | 热核爆炸核合成 |
| 占太阳系来源 | 30% |
| 主要反应 | 白矮星热核爆炸：爆炸性硅燃烧 → 铁族（⁵⁶Ni → ⁵⁶Co → ⁵⁶Fe） |
| 动画配方 | `explosion:Si28->Si28` |

**核素变化链：**

1. ²⁸Si(14p+14n) →（爆炸性核合成，示意）→ ²⁸Si(14p+14n)

白矮星吸积或并合触发碳氧热核爆炸（Ia 型超新星），主要生产铁族元素（Cr、Mn、Fe、Ni 等）。
