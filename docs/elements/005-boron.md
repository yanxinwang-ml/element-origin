# 硼 Boron（B）— 原子序数 5

## 基本信息

| 项目 | 内容 |
|---|---|
| 原子序数 | 5 |
| 符号 | B |
| 中文名 | 硼 |
| 英文名 | Boron |
| 发现 | Gay-Lussac（1808） |
| 太阳系丰度 | log ε ≈ 2.86（以氢 = 12 为基准） |

## 起源概述

硼同铍一样，主要由宇宙线散裂产生，是罕见的轻元素。

## 生成路径（1 条）

### 路径 1：宇宙线散裂（占比 100%）

| 项目 | 内容 |
|---|---|
| 生成场所 | 银河系星际介质 |
| 过程 | 宇宙线散裂（spallation） |
| 占太阳系来源 | 100% |
| 主要反应 | 高能 p + ¹²C / ¹⁴N / ¹⁶O → ¹⁰B / ¹¹B + 碎片 |
| 动画配方 | `spall:p+C14->B11` |

**核素变化链：**

1. p(1p+0n) + ¹⁴C(6p+8n) → ¹¹B(5p+6n) + 碎片

高能宇宙线撞击星际介质中较重的原子核，将其“打碎”成锂、铍、硼等轻元素。
