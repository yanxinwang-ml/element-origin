# 锂 Lithium（Li）— 原子序数 3

## 基本信息

| 项目 | 内容 |
|---|---|
| 原子序数 | 3 |
| 符号 | Li |
| 中文名 | 锂 |
| 英文名 | Lithium |
| 发现 | Arfvedson（1817） |
| 太阳系丰度 | log ε ≈ 3.33（以氢 = 12 为基准） |

## 起源概述

锂的来源很复杂：低质量恒星（AGB 星）、宇宙线散裂与大爆炸各占一部分，其“应该有多少”与观测不符，是天体物理中有名的“宇宙锂问题”。

## 生成路径（3 条）

### 路径 1：低质量恒星死亡（AGB 星，s-过程）（占比 64%）

| 项目 | 内容 |
|---|---|
| 生成场所 | AGB 星（低质量恒星晚期） |
| 过程 | s-过程（慢中子俘获） |
| 占太阳系来源 | 64% |
| 主要反应 | AGB 星：³He + ⁴He → ⁷Be →（电子俘获）⁷Li（Cameron–Fowler 机制） |
| 动画配方 | `fusion:He3+He4->Be7;ecap:Be7->Li7` |

**核素变化链：**

1. ³He(2p+1n) + ⁴He(2p+2n) → ⁷Be(4p+3n)
2. ⁷Be(4p+3n) + e⁻ → ⁷Li(3p+4n) + ν

低质量恒星演化到渐近巨星分支（AGB）时，慢中子俘获（s-过程）把种子核逐步推向锶、钡、铅等重元素，星风将产物吹回星际空间。

### 路径 2：大爆炸核合成（占比 23%）

| 项目 | 内容 |
|---|---|
| 生成场所 | 宇宙大爆炸（t ≈ 3–20 分钟） |
| 过程 | 大爆炸核合成（BBN） |
| 占太阳系来源 | 23% |
| 主要反应 | ⁷Be（电子俘获）→ ⁷Li（BBN 痕量合成） |
| 动画配方 | `ecap:Be7->Li7` |

**核素变化链：**

1. ⁷Be(4p+3n) + e⁻ → ⁷Li(3p+4n) + ν

宇宙诞生后最初约 3–20 分钟内，质子和中子结合成氢、氦及微量锂。

### 路径 3：宇宙线散裂（占比 14%）

| 项目 | 内容 |
|---|---|
| 生成场所 | 银河系星际介质 |
| 过程 | 宇宙线散裂（spallation） |
| 占太阳系来源 | 14% |
| 主要反应 | 高能宇宙线撞击 C/N/O 核 → ⁷Li + 碎片 |
| 动画配方 | `spall:p+C12->Li7` |

**核素变化链：**

1. p(1p+0n) + ¹²C(6p+6n) → ⁷Li(3p+4n) + 碎片

高能宇宙线撞击星际介质中较重的原子核，将其“打碎”成锂、铍、硼等轻元素。
