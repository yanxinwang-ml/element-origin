| 项目 | 内容 |

| 原子序数 | 6 |
| 符号 | C |
| 中文名 | 碳 |

| 太阳系丰度 | log ε ≈ 8.44（以氢 = 12 为基准） |

## 起源概述

碳约 3/4 来自低质量恒星（AGB 星）死亡时抛出的星风，其余来自大质量恒星。它是生命和有机化学的骨架。

## 生成路径（2 条）

### 路径 1：低质量恒星死亡（AGB 星，s-过程）（占比 75%）

| 项目 | 内容 |
|---|---|
| 生成场所 | AGB 星（低质量恒星晚期） |
| 过程 | s-过程（慢中子俘获） |
| 占太阳系来源 | 75% |
| 主要反应 | AGB 星氦壳燃烧：3 ⁴He → ¹²C（三氦过程），随星风抛射 |
| 动画配方 | `fusion:He4+He4->Be8;fusion:He4+Be8->C12` |

**核素变化链：**

1. ⁴He(2p+2n) + ⁴He(2p+2n) → ⁸Be(4p+4n)
2. ⁴He(2p+2n) + ⁸Be(4p+4n) → ¹²C(6p+6n)

低质量恒星演化到渐近巨星分支（AGB）时，慢中子俘获（s-过程）把种子核逐步推向锶、钡、铅等重元素，星风将产物吹回星际空间。

### 路径 2：大质量恒星核燃烧/超新星（占比 25%）

| 项目 | 内容 |
|---|---|
| 生成场所 | 大质量恒星内部 / 坍缩超新星 |
| 过程 | 恒星核燃烧 / 爆炸核合成 |
| 占太阳系来源 | 25% |
| 主要反应 | 大质量恒星氦燃烧：3 ⁴He → ¹²C（三氦过程） |
| 动画配方 | `fusion:He4+He4->Be8;fusion:He4+Be8->C12` |

**核素变化链：**

1. ⁴He(2p+2n) + ⁴He(2p+2n) → ⁸Be(4p+4n)
2. ⁴He(2p+2n) + ⁸Be(4p+4n) → ¹²C(6p+6n)

大质量恒星内部逐级燃烧氢、氦、碳、氖、氧、硅直到铁；坍缩超新星把产物抛回星际空间。
