# 铍 Beryllium（Be）— 原子序数 4

## 基本信息

| 项目 | 内容 |
|---|---|
| 原子序数 | 4 |
| 符号 | Be |
| 中文名 | 铍 |
| 英文名 | Beryllium |
| 发现 | Vaulquelin（1798） |
| 太阳系丰度 | log ε ≈ 1.37（以氢 = 12 为基准） |

## 起源概述

铍几乎全部由宇宙线散裂产生，宇宙中相当稀有。

## 生成路径（1 条）

### 路径 1：宇宙线散裂（占比 100%）

| 项目 | 内容 |
|---|---|
| 生成场所 | 银河系星际介质 |
| 过程 | 宇宙线散裂（spallation） |
| 占太阳系来源 | 100% |
| 主要反应 | 高能 p + ¹²C / ¹⁶O → ⁹Be + 碎片 |
| 动画配方 | `spall:p+C12->Be9` |

**核素变化链：**

1. p(1p+0n) + ¹²C(6p+6n) → ⁹Be(4p+5n) + 碎片

高能宇宙线撞击星际介质中较重的原子核，将其“打碎”成锂、铍、硼等轻元素。
